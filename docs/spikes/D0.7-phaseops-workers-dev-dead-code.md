# Spike D0.7 — `*.phaseops.workers.dev` wildcard routing is dead code

- **Date:** 2026-08-16
- **Method:** DNS + live HTTP probe
- **Result:** Confirmed dead code for Chrona Sites.

## Evidence

```
Resolve-DnsName whatever.phaseops.workers.dev
  A  188.114.97.0
  A  188.114.96.0          (Cloudflare workers.dev edge)

GET https://whatever.phaseops.workers.dev/__chrona_health
  HTTP 404  (error code 1042 — no worker script deployed on that name)
```

Workers subdomain for this account (verified via API): **`phaseops`** — so
`{name}.phaseops.workers.dev` is the platform wildcard namespace.

## Interpretation

- DNS resolves for **any** `*.phaseops.workers.dev` (platform wildcard), but serving only works
  when a worker script is actually deployed under that exact name.
- `whatever.phaseops.workers.dev` → 404/1042 = no matching worker → the wildcard URL scheme is
  not serving tenant content and never will.

## Conclusion

- Old legacy wildcard routing is dead; `resolveTenantFromHostname` no longer needs the
  `phaseops.workers.dev` branches (kept only as a harmless fallback, 1.8).
- Tenant traffic goes exclusively through `{project}.chronadocs.xyz` (ADR-0001) and custom
  hostnames (ADR-0012).

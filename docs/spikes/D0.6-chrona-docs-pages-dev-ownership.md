# Spike D0.6 — Who owns `chrona-docs.pages.dev`?

- **Date:** 2026-08-16
- **Method:** public DNS (1.1.1.1) + live HTTP check
- **Result:** **Owned by another Cloudflare account.**

## Evidence

```
Resolve-DnsName chrona-docs.pages.dev -Server 1.1.1.1 -Type A
  A  188.114.96.0
  A  188.114.97.0          (Cloudflare Pages edge, non-authoritative)
TXT: none
SOA: lorna.ns.cloudflare.com

GET https://chrona-docs.pages.dev/  ->  HTTP 200, serves a live site
```

## Interpretation

The name is registered to Cloudflare **Pages** (the A records are the Pages edge) and serves a
live 200 site — someone else's project. This is exactly the D2 bug: Pages project names are
**globally unique and frozen after creation**, so `chrona-docs` was taken by another account
and no retry/rename could recover the namespace.

## Conclusion

- Confirms ADR-0004: Pages is out of the tenant hosting path forever.
- `chrona-docs.pages.dev` cannot be reclaimed; we never reference it again.
- Tenant namespace must live on a zone we own (`chronadocs.xyz`, ADR-0001) where names are ours
  to allocate.

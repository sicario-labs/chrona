# Claim Intermediate Representation (Claim IR)

The formal data model of documentation assertions.

---

## Claim Structure

A `Claim` in Chrona is a structured representation of a factual assertion made by documentation:

```typescript
export interface Claim {
  id: string;
  type: ClaimType;
  subject: string;
  source: {
    file: string;
    line: number;
    column?: number;
    text: string;
  };
  evidence: Evidence[];
  status: ClaimStatus;
}
```

---

## Claim Lifecycle States

- **`unverified`**: Initial state; claim has been extracted but not yet matched against codebase evidence.
- **`verified`**: Authoritative AST evidence confirms that the assertion is 100% true.
- **`contradicted`**: AST evidence directly conflicts with the assertion (e.g. parameter removed or missing symbol).
- **`ambiguous`**: Conflicting evidence discovered across multiple definitions.

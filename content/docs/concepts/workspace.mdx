# The Chrona Workspace Model

The Workspace is the fundamental unit of truth uniting Software, Knowledge, Evidence, and Relationships.

---

## Workspace Architecture

```text
                 CHRONA WORKSPACE
                       │
        ┌──────────────┼──────────────┐
        │              │              │
     Software       Knowledge      Evidence
        │              │              │
        ▼              ▼              ▼
      Symbols        Claims         Sources
      APIs           Concepts       AST
      Types          Examples       Git
      Config         Guides         Schemas
      Commands       References     Runtime
        │              │              │
        └──────────────┼──────────────┘
                       │
                 RELATIONSHIPS
  (IMPLEMENTED_BY, DOCUMENTED_BY, USED_IN, EXPORTED_FROM, CHANGED_BY)
                       │
                       ▼
                 VERIFICATION
                       │
             ┌─────────┼─────────┐
             ▼         ▼         ▼
            CLI        CI       MCP
     (chrona workspace) (Gate) (get_verified_context)
```

---

## Workspace Submodels

1. **Software Model (`ws.software`)**:
   - Total exported symbols, types, and modules.
   - Map of extracted AST symbols with line spans, signatures, and deprecation flags.
2. **Knowledge Model (`ws.knowledge`)**:
   - Total documentation pages, claims, and verified count.
   - Code examples and conceptual guides.
3. **Evidence Model (`ws.evidence`)**:
   - AST ground truth status, Git commit hash, and package metadata.
4. **Integrity (`ws.integrity`)**:
   - Mathematical soundness score ($\frac{\text{Verified}}{\text{Verified} + \text{Contradictions}}$).
   - Breakdown of diagnostics by `DOC-xxx` code.
5. **Relationships (`ws.relationships`)**:
   - Relational graph connecting symbols, claims, examples, and Git commits.

# Monorepo Architecture

Chrona is structured as a high-performance documentation compiler monorepo organized into core engine packages and CLI interfaces:

```text
CHRONA MONOREPO
├── packages/
│   ├── engine/       # Documentation Verification Engine, Claim IR, Evidence Graph, AST Indexer
│   └── cli/          # Terminal CLI (`chrona check`, `chrona init`, `chrona impact`, `chrona mcp`)
└── content/
    └── docs/         # Dogfood MDX documentation verified by Chrona
```

## Package Overview

### `@chrona/engine` (`packages/engine`)
The core compiler engine. Extracts first-class Claim IR entities from MDX documents, resolves ground truth AST evidence from TypeScript codebases using `oxc` and `ts-morph`, and evaluates the diagnostic rule suite (`DOC-101`, `DOC-102`, `DOC-103`, `DOC-107`, `DOC-201`).

Key function:
```ts
import { DocumentationVerifier } from '@chrona/engine';

const verifier = new DocumentationVerifier();
const result = await verifier.verifyWorkspace();
console.log(`Verified ${result.summary.claimsVerified} claims.`);
```

### `@chrona/cli` (`packages/cli`)
The terminal-first compiler adapter. Provides commands:
- `chrona check`: Audit documentation claims against live codebase AST.
- `chrona impact`: Identify affected documentation claims when code changes in Git.
- `chrona init`: Bootstrap the Chrona Agent Workflow in any repository.
- `chrona mcp`: Expose verification tools to AI coding agents.

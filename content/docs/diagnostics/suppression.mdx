# Suppressing Diagnostics

How to suppress specific Chrona compiler diagnostics using inline pragmas and comments.

---

## Inline Pragma Comment (`<!-- chrona-ignore -->`)

To suppress diagnostics for an intentional deviation or historical documentation example, place a `<!-- chrona-ignore -->` comment immediately preceding the line or code block.

### Suppressing All Diagnostics for a Block

```markdown
<!-- chrona-ignore -->
```ts
// This legacy snippet is intentionally shown for migration purposes
const legacy = createOldRouter({ strict: true });
```
```

### Suppressing a Specific Rule Code

To suppress only a specific diagnostic code (e.g. `DOC-103` or `DOC-401`), pass the code to the pragma:

```markdown
<!-- chrona-ignore DOC-103 -->
```ts
const router = createRouter({ legacyMode: true });
```
```

### Suppressing Multiple Rule Codes

```markdown
<!-- chrona-ignore DOC-101 DOC-103 -->
```

---

## Workspace Configuration Suppressions

To disable a rule globally across your entire workspace, configure its severity to `'off'` in `chrona.config.ts`:

```typescript
export default {
  rules: {
    'DOC-401': 'off' // Disable deprecation warnings across all docs
  }
};
```

# Diagnostic Codes Reference (`DOC-xxx`)

Complete reference for all compiler diagnostics implemented in the Chrona Verification Engine.

---

## Code Matrix

| Code | Name | Default Severity | Description |
|---|---|---|---|
| [`DOC-101`](#doc-101-missing-symbol) | Missing Symbol / Missing Export | `error` | Documented symbol is not exported from the codebase |
| [`DOC-102`](#doc-102-signature-mismatch) | Signature Mismatch | `error` | Function signature in docs disagrees with codebase AST |
| [`DOC-103`](#doc-103-parameter-mismatch) | Parameter Mismatch | `error` | Phantom option or missing required parameter in docs |
| [`DOC-104`](#doc-104-contradicted-claim) | Contradicted Claim | `error` | Prose assertion directly contradicts live code behavior |
| [`DOC-107`](#doc-107-type-mismatch) | Type Mismatch | `error` | Documented type alias or interface structure does not match AST |
| [`DOC-201`](#doc-201-broken-example) | Broken Example | `error` | Code block in documentation fails static analysis or compilation |
| [`DOC-202`](#doc-202-recipe-regression) | Recipe Regression | `error` | Multi-step developer tutorial fails execution against current code |
| [`DOC-301`](#doc-301-broken-link) | Broken Link | `error` | Internal cross-reference or symbol link cannot be resolved |
| [`DOC-401`](#doc-401-deprecated-without-notice) | Deprecated Without Notice | `warning` | Deprecated symbol referenced in docs without deprecation banner |
| [`DOC-501`](#doc-501-task-degradation) | Task Degradation | `warning` | Developer Task Success Rate fell below baseline threshold |

## DOC-101: Missing Symbol

### Trigger
Emitted when documentation asserts that a function, class, type, or variable exists in a package, but the symbol cannot be resolved in any exported module.

### Example
```markdown
Import the nonexistent function:
<!-- chrona-ignore -->
```ts
import { runNonExistentHelper } from '@sample/lib';
```
```

### Remediation
- Export the missing symbol from `src/index.ts`.
- Or remove the reference from documentation if the symbol was deleted.

---

## DOC-102: Signature Mismatch

### Trigger
Emitted when a documented function signature declares a different return type or parameter structure than the AST ground truth.

### Remediation
Update the documented signature to match the return type declared in TypeScript AST.

---

## DOC-103: Parameter Mismatch

### Trigger
Emitted when a documented code example passes parameters that do not exist on the underlying function signature, or omits required positional arguments.

### Example
```markdown
```ts
// Error: createRouter takes 0 arguments, but docs pass an object!
const router = createRouter({ routes: ['/api'] });
```
```

### Remediation
Align the code snippet with the actual parameters accepted by the function.

---

## DOC-107: Type Mismatch

### Trigger
Emitted when a documented interface or type alias definition differs from the actual TypeScript AST definition.

---

## DOC-201: Broken Example

### Trigger
Emitted when a code example block fails static syntax parsing or imports non-existent modules.

---

## DOC-401: Deprecated Without Notice

### Trigger
Emitted when a function marked with JSDoc `@deprecated` in source code is referenced in documentation without warning users of its deprecation.

### Remediation
Add a deprecation note or callout in the documentation, or migrate the example to the recommended replacement API.

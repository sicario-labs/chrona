# Chrona Documentation

> **Software changes faster than its knowledge. Chrona maintains a continuously verifiable knowledge model of software.**

Chrona is a documentation verification compiler and epistemic truth engine for modern software projects. It analyzes source code AST, documentation claims, executable code snippets, Git history, and package metadata to ensure what your documentation asserts about your software is actually true.

## Core Capabilities

- **Documentation Type-Checking**: Detect code-documentation drift before users or coding agents do using `chrona check` and `chrona ci`.
- **AST Ground Truth Referee**: Uses the Rust-powered `oxc` parser to extract typed exports, signatures, parameters, and JSDoc deprecations in milliseconds.
- **Claim Intermediate Representation (Claim IR)**: Extracts structured assertions from Markdown/MDX prose and validates them against the codebase AST.
- **Git Change Intelligence**: Computes exact documentation impact (`chrona impact`) across Git commits and pull requests.
- **Epistemic Workspace Model**: The **Workspace** is the fundamental unit of truth (`chrona ws`) uniting Software, Knowledge, Evidence, and Relationships into a queryable graph.
- **Universal Multi-Agent MCP Integration**: Exposes `get_verified_context` and `get_workspace_model` to 20+ AI coding agent platforms (Cursor, Claude Code, Google Antigravity, Kiro, OpenAI Codex, Windsurf).

# Exit Codes Reference

Standardized process exit codes used across all Chrona CLI commands.

---

## Exit Code Table

| Exit Code | Meaning | Typical Scenarios |
|---|---|---|
| **`0`** | **Success** | All claims verified with 0 errors; CI gate passed; commands executed normally. |
| **`1`** | **Verification Failure** | Contradictions found during `chrona check` or `chrona ci`; CI fail threshold met. |
| **`2`** | **Fatal Error / Bad Configuration** | Missing or malformed config file; invalid CLI flags; unreadable directory. |

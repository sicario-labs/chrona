# Getting Started with Chrona

Getting started with Chrona takes under 10 seconds. You run a single terminal command inside your repository to prepare the AI agent workflow.

## 1. Run Chrona Init

In your repository terminal, run:

```bash
npx chrona init
```

### What `chrona init` does:
1. **Scans Project AST**: Detects TypeScript, framework types, README files, and public export signatures.
2. **Installs Agent Skill**: Places the Chrona Agent Skill into `.agents/skills/chrona/SKILL.md`.
3. **Creates Configuration**: Generates `.chrona/config.json` containing workspace parameters.
4. **Initializes Workspace**: Prepares the `content/docs/` directory for MDX content.

## 2. Instruct Your AI Agent

Once `chrona init` finishes, open your AI coding agent (Antigravity, Cursor, Claude Code) and prompt:

```text
Build the documentation for this project using Chrona.
```

Your agent will discover `.agents/skills/chrona/SKILL.md` and execute the 5-phase documentation loop automatically:

> [!TIP]
> **5-Phase Loop**: Discover $\rightarrow$ Plan $\rightarrow$ Write MDX $\rightarrow$ Validate $\rightarrow$ Report.

## 3. Verify Local Build

Validate the generated MDX documentation at any time by running:

```bash
npx chrona build
```

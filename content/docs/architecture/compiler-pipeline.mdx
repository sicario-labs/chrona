# Compiler Pipeline

Step-by-step walkthrough of the Chrona compilation and verification pipeline.

---

## The 5 Pipeline Stages

```text
1. Repository Snapshot Build
       │
       ▼
2. AST Symbol & Type Extraction (oxc-parser)
       │
       ▼
3. Documentation Claim Extraction (ClaimExtractor)
       │
       ▼
4. Evidence Resolution & Corroboration (EvidenceResolver)
       │
       ▼
5. Diagnostic Rules Execution & Report Generation (DEFAULT_RULES)
```

---

## 1. Snapshot Construction
Discovers all source files (`.ts`, `.tsx`, `.js`, `.jsx`, `.d.ts`) across `src/` and `packages/` while respecting `.gitignore`.

## 2. AST Extraction
Using `FastAstExtractor` backed by `oxc-parser`, parses each source file in $< 1\text{ms}$ to extract exported symbol signatures, parameter lists, default values, and JSDoc deprecation notices.

## 3. Claim Extraction
Scans MDX/Markdown files to parse headings, code blocks, parameter tables, and explicit prose claims into structured Claim IR.

## 4. Evidence Resolution
Matches each claim to the corresponding AST symbol in the repository snapshot.

## 5. Rule Evaluation
Evaluates all configured rules (`DOC-101` through `DOC-401`), producing the final `VerificationResult` and computing the `FalsePositiveTracker` precision metrics.

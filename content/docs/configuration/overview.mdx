# Configuration Overview

Chrona uses a unified configuration schema to govern source discovery, documentation paths, alias mapping, and compiler rules.

---

## Configuration File Locations

Chrona discovers configuration files in the following resolution order:
1. File explicitly passed via `--config <path>`
2. `cli.json`
3. `chrona.config.ts`
4. `chrona.config.json`
5. `.chronarc`

---

## Basic Configuration Example (`cli.json`)

```json
{
  "$schema": "node_modules/@chrona/cli/dist/schema.json",
  "baseDir": "src",
  "framework": "next",
  "uiLibrary": "base-ui",
  "aliases": {
    "uiDir": "./components/ui",
    "componentsDir": "./components",
    "layoutDir": "./layouts",
    "cssDir": "./styles",
    "libDir": "./lib"
  },
  "commands": {
    "format": "prettier --write"
  }
}
```

---

## TypeScript Configuration (`chrona.config.ts`)

```typescript
export default {
  baseDir: 'src',
  framework: 'next',
  uiLibrary: 'base-ui',
  rules: {
    'DOC-101': 'error',
    'DOC-102': 'error',
    'DOC-103': 'error',
    'DOC-401': 'warning'
  }
};
```

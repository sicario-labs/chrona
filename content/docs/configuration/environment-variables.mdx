# Environment Variables

Environment variables recognized by Chrona CLI, CI gates, and Cloud APIs.

---

## Recognized Environment Variables

| Variable | Default | Description |
|---|---|---|
| `CHRONA_API_URL` | `https://api.chronadocs.xyz` | Endpoint for Chrona Cloud verification ingestion and badge APIs |
| `CHRONA_API_KEY` | — | Organization API key (`chr_...`) for authenticating CI runs |
| `CHRONA_TOKEN` | — | Personal access token from `chrona login` |
| `CI` | — | When set to `true`, enables non-interactive mode and disables spinners |
| `GITHUB_ACTIONS` | — | When `true`, automatically enables GitHub Actions problem matcher annotations |
| `FORCE_COLOR` | — | Forces ANSI color output in CI logs |
| `NO_COLOR` | — | Strips all ANSI colors and escape sequences |

# chrona plan

Inspect compiler intermediate representation (Developer Tasks DAG and coverage).

---

## Usage

```bash
chrona plan [options]
```

## What it does

`chrona plan` analyzes the Developer Experience Graph (DX Graph IR) for the project, showing:
- Developer Tasks identified across your documentation.
- Prerequisites and step ordering.
- Sandboxed task recipes and executable example coverage.
- Next suggested tasks in the developer journey.

---

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `--cwd <path>` | `string` | `process.cwd()` | Working directory for the repository |
| `--json` | `boolean` | `false` | Output documentation plan as JSON (v1) |

---

## Examples

### View Developer Plan in Terminal

```bash
chrona plan
```

### Export Plan as JSON

```bash
chrona plan --json
```

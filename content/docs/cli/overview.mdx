# CLI Reference Overview

The Chrona Command Line Interface (`chrona`) provides developer-facing commands for local verification, CI/CD gates, change impact calculation, and agent integration.

---

## Global Usage

```bash
chrona [command] [options]
```

### Global Options

| Option | Type | Description |
|---|---|---|
| `--config <string>` | `string` | Custom path to configuration file (defaults to `cli.json` or `chrona.config.ts`) |
| `-V, --version` | `boolean` | Output the version number |
| `-h, --help` | `boolean` | Display help for command |

## Exit Codes

All Chrona commands adhere to standardized exit codes:

- **`0`**: Success (no verification errors detected).
- **`1`**: Verification failure (contradictions found or CI failure threshold met).
- **`2`**: Fatal configuration error, invalid CLI flags, or missing files.

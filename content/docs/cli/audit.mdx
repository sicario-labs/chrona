# chrona audit

Run zero-config verification audits across multiple repository archetypes and measure precision scorecards.

---

## Usage

```bash
chrona audit [options]
```

## What it does

`chrona audit` runs multi-repository verification benchmarks against a target corpus of codebases. It computes:
- Total claims detected
- Claims verified
- Contradictions found
- Verification duration in milliseconds
- Precision percentage ($\frac{\text{Verified}}{\text{Verified} + \text{Contradictions}}$)
- Pass/Warn/Fail status

---

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `--json` | `boolean` | `false` | Output audit matrix as structured JSON |

---

chrona audit

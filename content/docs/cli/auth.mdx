# Authentication Commands (`chrona login`, `chrona auth:*`)

Manage developer sessions and organization API keys for CI and cloud verification ingestion.

---

## chrona login

Authenticate your local terminal session using the RFC 8628 OAuth 2.0 Device Authorization Grant.

```bash
chrona login
```

Opens a verification URL in your browser with a one-time device code. Upon authorization, stores an access token in your global user config (`~/.chrona/auth.json`).

---

## chrona auth:create-key

Generate an organization-scoped API key (`chr_...`) for use in CI pipelines and automated agents.

```bash
chrona auth:create-key --name "GitHub Actions CI"
```

### Options
- `--name <name>`: Human-readable label for the API key.

---

## chrona auth:list-keys

List all active API keys for your organization.

```bash
chrona auth:list-keys
```

---

## chrona auth:revoke-key

Revoke an API key by ID, instantly invalidating its permissions.

```bash
chrona auth:revoke-key <id>
```

# chrona workspace (alias: chrona ws)

Inspect the epistemic model of the software workspace: sources, claims, evidence, relationships, and deep symbol explanations.

---

## Usage

```bash
chrona workspace [options]
chrona ws [options]
```

## What it does

The **Chrona Workspace** is the persistent epistemic model of your software environment. `chrona workspace` allows you to inspect:
1. **Sources**: Symbol counts, exports, types, and modules.
2. **Knowledge**: Documentation pages, claims, verified count, warnings, and contradictions.
3. **Evidence**: AST ground truth, Git history, and package metadata.
4. **Integrity**: Overall soundness percentage and diagnostic counts.
5. **Deep Explanation**: Inspect why a symbol has its current shape, which documentation references match or contradict it, and the exact evidence chain via `--explain <symbol>`.

---

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `--cwd <path>` | `string` | `process.cwd()` | Working directory for the repository |
| `--docs-dir <path>` | `string` | `content/docs` | Custom documentation directory |
| `--scope <name>` | `string` | — | Retrieve verified context with provenance for a specific symbol or scope |
| `--explain <symbol>` | `string` | — | Deep epistemic explanation for why a symbol looks like this and why docs drift |
| `--json` | `boolean` | `false` | Output full workspace model as structured JSON |

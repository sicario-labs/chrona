# chrona check

Audit documentation claims against live codebase AST and report compiler diagnostics.

---

## Usage

```bash
chrona check [options]
```

## What it does

`chrona check` is the primary local verification command. It:
1. Discovers and indexes all exported symbols, functions, types, and parameters in your project.
2. Extracts all explicit claims and code snippets from Markdown/MDX files in `content/docs/`.
3. Runs all enabled compiler rules (`DOC-101` through `DOC-401`).
4. Prints a formatted diagnostic summary or machine-readable JSON.

---

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `--cwd <path>` | `string` | `process.cwd()` | Working directory for the repository |
| `--diff [ref]` | `string \| boolean` | `HEAD~1` | Only check documentation claims affected by Git diff |
| `--since <ref>` | `string` | — | Alias for `--diff <ref>` |
| `--format <type>` | `'pretty' \| 'json' \| 'ndjson'` | `'pretty'` | Terminal formatting style |
| `--stream` | `boolean` | `false` | Stream incremental verification events as NDJSON |
| `--json` | `boolean` | `false` | Output verification report as machine-readable JSON (v1) |

---

## Examples

### Full Workspace Verification

```bash
chrona check
```

### Fast Scoped Check on Current PR Diff

```bash
# Check only files changed since the previous commit
chrona check --diff

# Check against main branch
chrona check --since main
```

### Machine-Readable JSON Output

```bash
chrona check --json
```

## Exit Codes

- `0`: All claims verified with zero errors.
- `1`: One or more compiler diagnostic errors found.
- `2`: Invalid options or unreadable directory.

# chrona impact

Calculate documentation impact across the Developer Experience Graph for code commits.

---

## Usage

```bash
chrona impact [options]
```

## What it does

`chrona impact` analyzes the AST differences introduced in recent Git commits and maps them to affected documentation claims, task DAGs, and code examples:
1. Computes AST export additions, removals, signature mutations, and parameter changes via `git diff`.
2. Identifies all documentation pages and claims that depend on modified symbols.
3. Generates a structured **Agent Work Order** specifying exact repairs needed.

---

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `--cwd <path>` | `string` | `process.cwd()` | Working directory for the repository |
| `--commit <hash>` | `string` | — | Specific commit hash to calculate impact for |
| `--since <ref>` | `string` | `HEAD~1` | Base Git reference or commit range |
| `--base <branch>` | `string` | — | Base branch to compare against (e.g. `main`) |
| `--json` | `boolean` | `false` | Output Agent Work Order as JSON (v1) |

---

## Examples

### Check Impact of Recent Staged/Local Changes

```bash
chrona impact
```

### Check Impact Against `main` Branch

```bash
chrona impact --base main
```

### JSON Agent Work Order Output

```bash
chrona impact --json
```

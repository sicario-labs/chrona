# chrona ci

Audit documentation truth in CI/CD pipelines with strict exit codes and GitHub Actions annotations.

---

## Usage

```bash
chrona ci [options]
```

## What it does

`chrona ci` is designed specifically for automated testing and CI runners. It:
1. Executes documentation verification across your repository.
2. Formats diagnostics as GitHub Actions workflow annotations (`::error file=...::`) or JUnit XML reports.
3. Enforces strict failure thresholds based on `--fail-on`.
4. Exits with non-zero code if any gate threshold is violated.

---

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `--cwd <path>` | `string` | `process.cwd()` | Working directory for the repository |
| `--fail-on <level>` | `'error' \| 'warn'` | `'error'` | Failure threshold to exit with code `1` |
| `--diff [ref]` | `string \| boolean` | `HEAD~1` | Only verify documentation affected by Git diff |
| `--since <ref>` | `string` | — | Base Git reference (alias for `--diff`) |
| `--format <format>` | `'pretty' \| 'json' \| 'ndjson' \| 'junit' \| 'github'` | Auto | Report output format |
| `--output <path>` | `string` | — | Write output report to specific file path |

---

## Examples

### Basic CI Gate

```bash
chrona ci --fail-on error
```

### GitHub Actions Workflow

When running inside GitHub Actions, Chrona automatically detects `GITHUB_ACTIONS=true` and outputs workflow annotations:

```yaml
- name: Run Chrona Truth Gate
  run: npx chrona ci --format github
```

### Generating a JUnit XML Report

```bash
chrona ci --format junit --output test-results/chrona-report.xml
```

---

## Exit Codes

- `0`: Pass (no diagnostics exceeded the `--fail-on` threshold).
- `1`: Fail (diagnostics exceeded threshold, e.g. errors found).
- `2`: Internal error or invalid configuration.

# Environment Variable Commands (`chrona env`)

Manage per-project environment variables for edge-hosted documentation.

---

## chrona env set

Set an environment variable for the current project.

```bash
chrona env set <key> <value> [options]
```

### Example
```bash
chrona env set API_BASE_URL https://api.example.com
```

---

## chrona env get

Retrieve the value of an environment variable.

```bash
chrona env get <key> [options]
```

---

## chrona env unset

Remove an environment variable.

```bash
chrona env unset <key> [options]
```

---

## chrona env ls

List all configured environment variables for the current project.

```bash
chrona env ls [options]
```

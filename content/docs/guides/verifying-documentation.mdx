# Verifying Documentation

A comprehensive guide on running and customizing documentation verification workflows.

---

## Local Verification Workflow

During everyday development, run `chrona check` before committing code changes:

```bash
npx chrona check
```

Chrona performs single-pass parsing across all source files in your project and validates every assertion in `content/docs/`.

---

## Configuring Documentation Paths

By default, Chrona verifies Markdown and MDX files in `content/docs/`. If your project stores documentation in another directory (such as `docs/`), specify it via:

```bash
npx chrona check --cwd . --docs-dir docs
```

Or configure `docsDir` in `cli.json` or `chrona.config.ts`.

---

## Continuous Verification in Dev Mode

When authoring documentation, start the live dev server:

```bash
npx chrona dev
```

Chrona watches both your source code and your MDX files. If an API signature changes in code, the documentation preview highlights contradicted claims in real time.

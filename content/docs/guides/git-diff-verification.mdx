# Git Diff Verification

Restricting verification to documentation affected by changed code in pull requests.

---

## Scoped Verification (`--diff` / `--since`)

On repositories with hundreds of documentation pages, verifying only the claims affected by your branch's Git diff provides instantaneous feedback:

```bash
# Check claims affected by commits on current branch relative to main
npx chrona check --since main
```

---

## How It Works

1. **AST Change Extraction**: Chrona analyzes the Git commit diff (`git diff main...HEAD`) to identify which functions, interfaces, or exports were modified.
2. **Impact Graph Traversal**: Chrona traverses the workspace relationship graph to identify which documentation claims reference those specific symbols.
3. **Targeted Verification**: Runs rule verification only on the affected subset of claims.

---

## Using in CI Pull Request Workflows

```yaml
- name: Verify Documentation on PR Diff
  run: npx chrona ci --since origin/main --fail-on error
```

# Troubleshooting

Common real-world issues, diagnostic resolutions, and failure modes.

---

## 1. "No documentation detected" / 0 claims found

### Cause
Chrona looks in `content/docs/` by default. If your documentation is located in `docs/` or another folder, no files were indexed.

### Solution
Pass `--docs-dir <path>` or set `docsDir` in `cli.json`:

```bash
npx chrona check --docs-dir docs
```

---

## 2. DOC-101 on a valid export

### Cause
The symbol is exported internally, but not exported from the package's primary entrypoint (`src/index.ts`).

### Solution
Ensure `export { mySymbol } from './internal'` exists in your main entrypoint.

---

## 3. Git Diff Fails in CI ("shallow clone / unknown revision")

### Cause
GitHub Actions defaults to `fetch-depth: 1`, which does not include the base commit for `--diff` or `--since`.

### Solution
Configure `fetch-depth: 0` in your checkout action:

```yaml
- uses: actions/checkout@v4
  with:
    fetch-depth: 0
```

---

## 4. MCP Server Connection Issues

### Cause
The AI coding agent cannot locate the `chrona` binary in its environment.

### Solution
Use `npx @chrona-engine/cli mcp` as the command in your agent configuration, or install `@chrona-engine/cli` globally with `npm i -g @chrona-engine/cli`.

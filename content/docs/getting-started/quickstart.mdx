# Quickstart

Get from zero to verified documentation in under 60 seconds.

---

## 1. Initialize Chrona in Your Project

Run the initialization wizard in your project root:

```bash
npx chrona init
```

This scans your repository, detects your source and documentation directories, and creates your initial task DAG and configuration.

### Optional Git Pre-Commit Hook
You can automatically install a pre-commit hook during initialization:

```bash
npx chrona init --hook warn
```

Options for `--hook`:
- `none` (default): Do not configure a hook.
- `warn`: Non-blocking terminal warning when staged commits introduce documentation drift.
- `strict`: Blocks commits if `chrona check` detects contradictions.

---

## 2. Run Your First Verification Audit

Execute the verification engine against your documentation:

```bash
npx chrona check
```

Chrona extracts claims from your documentation files and verifies them against your TypeScript/JavaScript AST.

### Example Output:
```text
=== Chrona Verification Report ===

  ✔ 33 claims verified
  ✖ 1 contradiction found
  ○ 15 unverified narrative claims

Diagnostics:
  ✖ [DOC-103] Phantom option `{ routes }` not accepted by `createRouter`
    at content/docs/api-reference.mdx:40
    Evidence: Parameter `routes` was removed in commit 68f6d87.
```

---

## 3. Inspect Deep Symbol Explanation

When Chrona reports a contradiction or when you want to inspect how a symbol is modeled across code and docs, run:

```bash
npx chrona ws --explain createRouter
```

This traverses the workspace epistemic graph and prints the exact AST implementation signature, documentation references, git change ref, and epistemic verdict.

---

## 4. Add Chrona to Your CI Pipeline

Add Chrona as a verification gate in your GitHub Actions workflow:

```yaml
# .github/workflows/chrona.yml
name: Chrona Truth Gate
on: [pull_request, push]

jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'
      - run: pnpm install
      - run: npx chrona ci --fail-on error
```

If documentation contradicts the codebase, `chrona ci` exits with code `1` and emits GitHub pull request annotations.

# Installation

Chrona is distributed as an npm package. You can install it locally as a development dependency or execute it directly without prior installation using `npx` or `pnpm dlx`.

---

## System Requirements

- **Node.js**: `v18.0.0` or higher (`v20+` or `v22+` recommended)
- **Package Managers**: `pnpm`, `npm`, `yarn`, or `bun`
- **Operating Systems**: macOS, Linux, Windows (PowerShell / WSL / CMD)
- **Git**: `v2.20+` (optional, for change intelligence and Git-diff verification)

---

## Installation Methods

### Project-Local Installation (Recommended)

Installing Chrona locally ensures everyone on your team and your CI pipeline runs the exact same version.

```bash npm2yarn
npm install -D @chrona-engine/cli @chrona/engine
```

```bash
# Using pnpm
pnpm add -D @chrona-engine/cli @chrona/engine

# Using yarn
yarn add -D @chrona-engine/cli @chrona/engine

# Using bun
bun add -d @chrona-engine/cli @chrona/engine
```

### Global Installation

To make `chrona` globally accessible across all terminal sessions:

```bash
npm install -g @chrona-engine/cli
```

### Zero-Install Execution

Run commands on demand without adding dependencies to your `package.json`:

```bash
# Verify documentation directly
npx @chrona-engine/cli check

# Run workspace scorecard
npx @chrona-engine/cli workspace
```

---

## Verifying the Installation

Check the installed CLI version:

```bash
npx chrona --version
```

Verify that the CLI help menu is available:

```bash
npx chrona --help
```

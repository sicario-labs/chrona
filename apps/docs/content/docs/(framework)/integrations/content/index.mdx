## Introduction

**Chrona is very flexible.** You can integrate with any content source, even without an official adapter.

### Examples

You can see examples to use Chrona with a CMS, which allows a nice experience on publishing content, and real-time update without re-building the app.

- [BaseHub](https://github.com/fuma-nama/chrona-basehub)
- [Sanity](https://github.com/fuma-nama/chrona-sanity)
- [Community: Payload CMS by `MFarabi619`](https://github.com/MFarabi619/chrona-payloadcms)
- [Community: Payload CMS by `bapspatil`](https://github.com/bapspatil/chrona-payload-template)

Not enough? [Build your own content source](/docs/integrations/content/custom).

## What is this?

Chrona Core offers server-side functions and headless components to build docs on React.js frameworks like Next.js, Waku, and Astro with React islands.

- Search (built-in: ZBSearch, Algolia Search)
- Breadcrumb, Sidebar, TOC Components
- Remark/Rehype Plugins
- Additional utilities

<Callout title="Tip">

    It can be used without Chrona UI, in other words, it's headless.

    For beginners and normal usages, use [Chrona UI](/docs/ui).

</Callout>

## Installation

No other dependencies required.

```package-install
chrona-core
```

For some components, a framework provider is needed:

```tsx tab="Next.js"
import type { ReactNode } from 'react';
import { NextProvider } from 'chrona-core/framework/next';

export function RootLayout({ children }: { children: ReactNode }) {
  // or if you're using Chrona UI, use `<RootProvider />`
  return <NextProvider>{children}</NextProvider>;
}
```

```tsx tab="React Router"
import type { ReactNode } from 'react';
import { ReactRouterProvider } from 'chrona-core/framework/react-router';

export function Root({ children }: { children: ReactNode }) {
  return <ReactRouterProvider>{children}</ReactRouterProvider>;
}
```

```tsx tab="Tanstack Start/Router"
import type { ReactNode } from 'react';
import { TanstackProvider } from 'chrona-core/framework/tanstack';

export function Root({ children }: { children: ReactNode }) {
  return <TanstackProvider>{children}</TanstackProvider>;
}
```

```tsx tab="Waku"
import type { ReactNode } from 'react';
import { WakuProvider } from 'chrona-core/framework/waku';

export function Root({ children }: { children: ReactNode }) {
  return <WakuProvider>{children}</WakuProvider>;
}
```

```tsx tab="Astro"
import type { ReactNode } from 'react';
import { AstroProvider } from 'chrona-core/framework/astro';

export function DocsIsland({
  children,
  pathname,
  params,
}: {
  children: ReactNode;
  pathname: string;
  params: Record<string, string | string[] | undefined>;
}) {
  return (
    <AstroProvider pathname={pathname} params={params}>
      {children}
    </AstroProvider>
  );
}
```

It offers simple document searching as well as components for building a
good docs.

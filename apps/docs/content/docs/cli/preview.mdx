---

## Introduction

`chrona-preview` allows you to view Markdown files with Chrona, it is useful for reading skills files & notes.

Run the command under your project directory.

```npm
npx chrona-preview dir/to/content
```

### Configurations

For other configurations, you can install it locally:

```npm
npm install chrona-preview -D
```

Then init the config file:

```npm
npx chrona-preview init
```

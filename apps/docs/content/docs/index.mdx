# The Typechecker for Documentation

Welcome to **Chrona**. Chrona is not just a documentation generator—it is a strict compiler that treats your documentation as verifiable code.

Most documentation decays the moment it is written because it lives completely disconnected from the source code. Chrona solves this by compiling an **Epistemic Model** of your workspace and mathematically verifying your documentation claims against the Abstract Syntax Tree (AST) ground truth.

## Why Chrona?

Documentation should be a reliable contract, not a loose suggestion. By treating English text as a compiler target, Chrona ensures that:

1. **No Phantom APIs:** You can never document a function, property, or option that doesn't actually exist in the code.
2. **Refactor Safety:** When you rename a function or change a signature in TypeScript, Chrona immediately flags every affected markdown file.
3. **Continuous Verification:** Running \chrona check\ provides cryptographic proof that your documentation exactly matches code reality.
